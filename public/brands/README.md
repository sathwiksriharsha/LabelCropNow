# LabelCropNow brand assets

Use these files as local assets under public/brands. The bundle intentionally does not fabricate logos for brands whose assets could not be verified.

## Important
- A permissive copyright license for an image does not grant trademark rights or mean a company endorses LabelCropNow.
- Use logos only to identify the marketplace/courier/printer being supported, without suggesting partnership or endorsement.
- Several downloaded official-site assets have no independently verified re-use permission. Review each row in asset-manifest.csv before public production.
- Do not display assets under restricted-review/ until permissions have been checked. For UPS and USPS, use plain-text labels for now.
- If an asset is old, unclear, or not permitted, use the brand name as text instead of recoloring, redrawing, or inventing a replacement.
- Preserve logo proportions and native colors. Use object-fit: contain; do not crop, stretch, recolor, or add effects.
- Meesho JPG is a square lockup with a dark-purple background. It is not a transparent wordmark.
- Some Simple Icons assets are single-color brand marks/glyphs, not complete multicolor wordmark lockups. Pair them with the brand name as text.
