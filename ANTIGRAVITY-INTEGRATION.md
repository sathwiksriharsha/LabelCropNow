# Antigravity integration instructions — LabelCropNow logos

1. Merge the included public/brands folder into the root of the Astro project so files land in public/brands/.
2. Implement a reusable BrandLogo.astro component with a typed brand-to-path map, accessible alt text, intrinsic aspect ratios, object-fit: contain, and a text-only fallback.
3. Use genuine bundled assets only where the manifest says the file is suitable and current enough. Keep simple-icons glyphs next to a text brand name; they are not always complete wordmarks.
4. Do not use anything under public/brands/restricted-review/ until legal/brand usage permission has been checked. Use plain text for UPS and USPS meanwhile.
5. For brands in text-fallbacks.json with no logo file, use a plain textual brand name—never generate or approximate a logo.
6. Do not hotlink the original sources. Keep the local asset files and manifest.
7. Preserve colors and ratios. Use the actual logo as downloaded; no filters, recoloring, cropping, stretching, or effects.
8. Add or retain a small brand-assets credits section/page with the Myntra and Snapdeal CC BY-SA 4.0 attribution. Do not imply official partnership.
9. Test logo rendering in marketplace selectors, supported-platform rows, courier filters and printer compatibility sections at desktop/mobile widths.
10. https://labelcrop.pages.dev is the requested site URL; this asset bundle does not change canonical configuration.
